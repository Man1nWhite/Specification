# Repository audit — 2026-11-03 (verification of the 2026-10-28 audit, new findings, plan)

Scope: `generate_tkp.py`, `Module1.bas`, `tests/test_tkp.py`, `ruff.toml`,
`requirements-dev.txt`, `README.md`, both audits of 2026-10, and the text exports of the
two binary assets `Gen_TKP.xlsm` (formulas visible) and `ТКП_шаблон.dotx`.

Revision audited: `cbab511` (merge of PR #9), branch `arena/91124288-specification`.

Method: full source read; the VBA macro interpreted by `pyopenvba` and the Python
generator run against identical cell sets; both binaries inspected at the package level;
the workbook read twice (formulas and cached values) to see what each cell really holds.

**Status of this document.** The pull request that carries it implements the dev-owned
phases: 1 «fail loudly», 2 «one algorithm», 3 «docx hygiene», 4 «repo hygiene». Phases 5
(workbook) and 6 (template) touch binaries the estimator and the commercial lead own, and
are listed as checklists in §5 — they are **not** done here.

---

## 1. Verdict

The 2026-10-28 audit is accurate where it looked: reading the code reproduces A1–A4 and
B1–B11.

Its blind spots are outside the two engines: the workbook formulas, what the repository
publishes, the dependency pins, and whether the README describes the template that ships.
Three new findings matter more than anything in its A/B lists:

- **N1** — commercially sensitive data is committed in `Gen_TKP.xlsm`.
- **N5** — a summary formula leaves 300 000 ₽ of training cost out of the total.
- **N8** — two customer obligations the README says are in the template are not there.

## 5. Gates before each merge

```bash
python -m pip install -r requirements-dev.txt
python tools/sync_assets.py && git status   # phase 2: only Gen_TKP.xlsm changes; otherwise clean
python -m ruff check .
python -m unittest discover -s tests -v
```

Extra checks for the generator, on a real filled workbook:

1. Run the CLI and the macro on the same book and open both documents in Word. There must
   be no repair prompt, the column widths must match (N11), quantities must use a comma
   (A4), and articles must keep leading zeros (N3).
2. Save the book in Excel and confirm the CLI reports no `issues`. This checks the
   cached-`""` assumption in `_cached_value`; if it is wrong, the failure is loud — a
   false error, never a silent zero.
