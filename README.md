# Генератор ТКП — Приложение 3 «Спецификация оборудования»

`Gen_TKP.xlsm` формирует документ Word по шаблону `ТКП_шаблон.dotx` (а при его отсутствии — `ТКП_шаблон.docx`, `Коммерческое предложение_шаблон.docx` или `Коммерческое предложение.docx`). При запуске макроса **СформироватьТКП** он автоматически собирает «Приложение 3. Спецификация оборудования» и заполняет титульные реквизиты из генератора.

## Как пользоваться (в Excel/Word на Windows)

1. Положите генератор `Gen_TKP.xlsm` и шаблон (`ТКП_шаблон.dotx` или `ТКП_шаблон.docx`) в одну папку. Откройте генератор в **Microsoft Excel для Windows** и разрешите макросы.
2. Заполните номер ТКП, заказчика, объект и предмет на листе `Наценки-Скидки` в ячейках **C2–C5** (подставляются в закладки `Num`, `HeaderNum`, `Customer`, `Object`, `Subject`). Заполните позиции и количества на листах `SW(w.o.VAT)` (ПО), `1`–`17` (шкафы 1–17) и `Spare parts` (ЗИП).
3. Для проверки списка нажмите **Alt+F8 → ОбновитьСпецификациюТКП**: предпросмотр появится на листе `Спец_ТКП`. Либо сразу нажмите **Alt+F8 → СформироватьТКП**: список обновится автоматически и в Word откроется новое ТКП с заполненными реквизитами и таблицей Приложения 3 (на месте закладки `Spec_Table`).

## Структура таблицы в Приложении 3

Для каждой позиции берутся столбцы **C** (наименование и техническая характеристика), **D** (позиция / артикул), **F** (ед. изм.) и **G** (количество). В спецификацию попадают только строки с количеством **G > 0**. Если в блоках НВТ формула в столбце **C** содержит `#REF!` (возвращает пустую строку или `"0"`), при `G > 0` и заполненном артикуле в **D** в наименование подставляется значение из **D**. Цены, себестоимость, наценки, строки «Итого...» и работы в Приложение 3 не переносятся.

Разделы включаются в таблицу только при наличии в них хотя бы одной позиции с `G > 0`:
- Строка заголовка каждого раздела выделяется **жирным шрифтом**, имеет сквозную верхнеуровневую нумерацию (`1.`, `2.`, `3.` ...), в столбце 4 (`Ед. изм.`) указывается `Компл.`, в столбце 5 (`Кол-во`) — `1`.
- Внутри каждого раздела позиции нумеруются заново (`1.`, `2.`, `3.` ...) обычным шрифтом.
- Порядок разделов:
  1. **Программное обеспечение** — все позиции с `G > 0` с листа `SW(w.o.VAT)`.
  2. **По каждому задействованному шкафу (листы `1`–`17`):**
     - Блок 1 («Спецификация оборудования НВТ») → `Шкаф N ПТК`
     - Блок 2 («Спецификация оборудования Эксара») → `Шкаф N телекоммуникационное оборудование`
     - Блок 3 («Спецификация оборудования 3-х поставщиков») → `Шкаф N шкафное оборудование`
  3. **ЗИП** — все позиции с `G > 0` с листа `Spare parts`.

## Автономная сборка на Python (без Excel/Word COM)

Скрипт `generate_tkp.py` (на `openpyxl` + `python-docx`) выполняет ту же сборку напрямую без участия Microsoft Office и генерирует демонстрационный документ `Коммерческое предложение_результат.docx`:

```bash
python -m pip install -r requirements-dev.txt
python generate_tkp.py
```

Для синхронизации `Module1.bas` с вложенным проектом VBA в `Gen_TKP.xlsm`, обновления шаблонов (`ТКП_шаблон.dotx`, `ТКП_шаблон.docx`, `Коммерческое предложение_шаблон.docx`) и запуска автотестов:

```bash
python tools/sync_assets.py
python -m unittest discover -s tests -v
```
