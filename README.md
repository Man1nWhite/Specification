# Генератор ТКП — Приложение 3 «Спецификация»

`Gen_TKP.xlsm` формирует документ Word по `ТКП_шаблон.dotx`. При запуске макроса **СформироватьТКП** он теперь сам собирает Приложение 3 из генератора — вручную заполнять лист `Спец_ТКП` не нужно.

## Как пользоваться

1. Положите **оба файла** (`Gen_TKP.xlsm` и `ТКП_шаблон.dotx`) в одну папку. Откройте генератор в **Microsoft Excel для Windows** и разрешите макросы; для создания документа нужен Microsoft Word.
2. Заполните номер, заказчика и объект на листе `Наценки-Скидки` в ячейках **C2–C4**. Заполните позиции и количества на листах `1`–`17`, `Spare parts` (ЗИП) и `SW(w.o.VAT)` (ПО).
3. Для проверки списка нажмите **Alt+F8 → ОбновитьСпецификациюТКП**: результат появится на листе `Спец_ТКП`. Либо сразу нажмите **Alt+F8 → СформироватьТКП**: список обновится автоматически и в Word откроется новое ТКП с заполненной таблицей Приложения 3. Сохраните созданный документ в Word обычным способом.

Для каждой позиции берутся **C** (наименование/техническое описание), **D** (артикул), **F** (единица измерения) и **G** (количество). Включаются только позиции с количеством **больше нуля**. Одинаковые позиции с одинаковыми наименованием, артикулом и единицей измерения внутри одного раздела объединяются, их количества складываются. Разделы без позиций не выводятся. Цены, итоги и работы в Приложение 3 не попадают.

Если формула наименования (C) пока не работает (например, старая ссылка `#REF!`), используется артикул (D). Если при положительном количестве нет ни наименования, ни артикула **или** не указана единица измерения (F), создание останавливается с указанием листа и строки — чтобы не выпустить неполную спецификацию. Лист `Спец_ТКП` — только предпросмотр: правки в нём будут заменены при следующем запуске; меняйте исходные листы.

## Поддержка проекта

Читаемая версия встроенного макроса — `Module1.bas`. Для синхронизации его с защищённым проектом VBA в книге и для настройки закладок Word-шаблона:

```bash
python -m pip install -r requirements-dev.txt
python tools/sync_assets.py
python -m unittest discover -s tests -v
```

Пароль проекта VBA не изменяется и не требуется для запуска макроса. Автотесты проверяют сборку данных и структуру шаблона без Office; создание Word-документа следует также проверить в установленном Excel/Word на Windows.
